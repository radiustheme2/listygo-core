Listygo Core is the essential companion plugin for the Listygo Directory Theme.
It adds advanced search widgets, optimization features, Elementor widgets, and other tools to enhance your directory site.

== Description ==

Listygo Core Plugin enhances your Listygo Directory Theme with features like:

* Advanced search widgets
* Elementor widget integration
* Preload & preconnect optimization for Google PageSpeed and GTmetrix
* Lazy load background image support
* Custom post types and fields for listings
* Social sharing options

This plugin is required for the full functionality of the Listygo Theme.

== Installation ==

1. Upload the `listygo-core` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Make sure the Listygo Directory Theme is active.
4. Configure plugin options via the WordPress Customizer or Elementor widgets.

== Frequently Asked Questions ==

= Is Listygo Core required for my theme? =
Yes, it is required for all advanced features, widgets, and directory functionalities to work properly.

= Can I use this plugin with other themes? =
It is designed specifically for the Listygo Directory Theme. Some features may not work with other themes.

= Does it improve website performance? =
Yes. Features like preload, preconnect, and lazy loading optimize your website for better performance scores.
